# Bheemshetty Ankitha | Portfolio

Personal portfolio website of **Bheemshetty Ankitha**, Computer Science graduate (B.Tech) from Hyderabad.

🌐 **Live Website:** [https://bheemshettyankitha.github.io/](https://bheemshettyankitha.github.io/)

---

## 🚀 Overview

A modern, responsive, and lightweight personal portfolio website:
- **White & Black Themes:** Smooth theme toggle with preference saved in `localStorage`.
- **Categorized Skills:** Rectangular badges with tech icons for Programming Languages, Web Development, Databases, and Tools.
- **Academic Qualifications:** Clean overview of education (B.Tech at JPNCE, Intermediate, SSC).
- **Selected Projects:**
  - **DineSpot:** Android restaurant booking and table tracking application.
  - **Human Stress Detection:** Machine learning predictive model with Flask web interface.
- **Certificates:** Prompt Engineering Research & Integration Remote Internship supported by Rochester Institute of Technology (RIT) & Excelerate.
- **Contact:** Clickable links for Email, LinkedIn, GitHub, and a connected Formspree contact form.

---

## 🛠️ Built With

- **HTML5:** Semantic, accessible markup.
- **CSS3:** Custom responsive layout, CSS variables, and fluid transitions.
- **JavaScript (ES6+):** Pure vanilla JavaScript (theme toggle, sticky mobile navigation, scroll spy, and form handling).
- **Vite:** High-performance local development and build tooling.

---

## 💻 Run Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
